# 樱愿召唤卡面美术约束

- 运行时卡面采用 2:3 竖构图，不把卡框、稀有度文字或 UI 烧进图片。
- 视觉品质依靠人物轮廓、光线、材质和大色块，不依靠密集装饰。
- 每套服装最多保留一个主要纹章和少量边缘饰线。
- 禁止锁链、网状雕纹、重复微型花纹、密集条纹、成串流苏和碎小挂件。
- 背景使用大块天空、建筑与光影，避免枝条、旗帜、星轨同时堆满画面。
- N / SR / SSR / UR 分别通过光线与色彩提升强度，人物细节密度保持一致。
- 角色必须单人、头部和双手完整、无文字、无签名、无水印。
