## Redis 决策

当前单实例部署不把 Redis 作为 P0/P1 前置条件。业务真相继续落 SQLite，并优先规划 PostgreSQL；只有多实例时再用 Redis 承担限流、WebSocket Pub/Sub、在线状态、短 TTL 热点缓存和赛马 leader lock。余额、下注、进度、消息和运营配置不能以 Redis 为唯一存储。
