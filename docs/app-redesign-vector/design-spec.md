# Sakura App Frontend Redesign

本设计只覆盖前端视觉与交互方向，不包含代码实现。

## 设计目标

- 让五个主入口形成统一的阅读产品气质：轻、清晰、信息密度适中。
- 强化阅读、书架、社区、消息、我的之间的层级差异。
- 保留 8px 内部卡片圆角、低阴影、浅边框的项目既有设计约束。
- 使用多色但克制的功能色：蓝色负责行动，粉色负责樱花品牌情绪，金色负责会员与奖励，绿色负责健康/完成状态。

## 主入口策略

### 发现

首页定位为“找内容”。首屏包含搜索、今晚推荐、分类快捷入口和榜单更新。

核心体验：
- 搜索入口常驻顶部。
- 推荐卡承载当前主推内容。
- 分类入口四宫格降低选择成本。
- 榜单卡只展示关键增长信息，避免信息过载。

### 书架

书架定位为“回到阅读”。首屏强调继续阅读和收藏书籍。

核心体验：
- 继续阅读卡突出章节、进度和封面。
- 收藏书籍用紧凑卡片展示。
- 书源健康卡放在首屏，减少用户对可用性的焦虑。

### 社区

社区定位为“读后交流”。动态发布框、动态卡、聊天室和任务中心并列。

核心体验：
- 发布入口弱输入化，不打扰浏览。
- 动态卡聚焦用户、作品和一句核心内容。
- 聊天室与任务中心做成两个操作卡，形成轻社区感。

### 消息

消息定位为“提醒收纳”。按互动、系统、奖励分组。

核心体验：
- 消息项采用头像/图标、标题、摘要、角标结构。
- 重要提醒置顶，弱提醒折叠。
- 提供“全部已读”低干扰动作。

### 我的

我的定位为“身份和成长”。承接会员等级、统计、签到与服务入口。

核心体验：
- 会员卡作为身份核心。
- 统计面板紧跟会员卡。
- 签到卡保持轻任务感。
- 服务区只展示高频入口，更多入口可下钻。

## 组件规则

- 卡片：8px radius，1px border，浅阴影仅用于浮层或首屏重点卡。
- 按钮：主按钮使用品牌蓝渐变；会员/奖励按钮使用金色；普通操作用描边或浅底。
- 底部导航：选中态使用蓝色圆形底，标签加粗；未选中保持中性灰。
- 字号：页面标题 26/900，小标题 18/900，正文 14，说明 12。
